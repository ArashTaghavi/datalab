تحلیل و مقایسه Box Plot برای توزیع‌های تک‌قله‌ای و چندقله‌ای

۱. مقدمه: Box Plot چیست؟

Box Plot یا نمودار جعبه‌ای یکی از ابزارهای مهم برای خلاصه‌سازی و مقایسه‌ی توزیع داده‌های عددی است. این نمودار به‌جای نمایش تک‌تک مقادیر، اطلاعات اصلی توزیع را در قالب چند مقدار آماری نمایش می‌دهد.

مهم‌ترین بخش‌های Box Plot عبارت‌اند از: Q1، Median، Q3، IQR و Whiskers. همچنین مقادیر غیرعادی ممکن است به‌صورت Outlier در خارج از Whiskerها نمایش داده شوند.

بخش نام مفهوم
Q1 First Quartile ۲۵٪ داده‌ها پایین‌تر از این مقدار هستند
Median Median ۵۰٪ داده‌ها پایین‌تر و ۵۰٪ بالاتر هستند
Q3 Third Quartile ۷۵٪ داده‌ها پایین‌تر از این مقدار هستند
IQR Interquartile Range فاصله بین Q1 و Q3
Whiskers Whiskers محدوده‌ی داده‌های غیرپرت
Outlier Outlier مقدار غیرعادی خارج از محدوده‌ی Whisker
نکته مهم: Box Plot شکل دقیق Distribution را نشان نمی‌دهد. برای مثال ممکن است یک Box Plot برای یک توزیع تک‌قله‌ای و یک توزیع دو‌قله‌ای بسیار شبیه باشد. بنابراین برای بررسی تعداد قله‌ها، Box Plot باید در کنار نمودارهایی مانند KDE یا Histogram استفاده شود.

۲. داده‌های مورد بررسی

در این تحلیل، پنج دیتاست با ساختارهای مختلف Distribution مورد بررسی قرار گرفته‌اند. هدف این است که ببینیم تغییر شکل Distribution از تک‌قله‌ای به چندقله‌ای چگونه در Box Plot دیده می‌شود.

دیتاست ساختار تعداد نمونه پارامترهای اصلی
Unimodal تک‌قله‌ای 1000 Mean = 170, SD = 8
Bimodal - Balanced دو قله‌ی متعادل 1000 155 و 185
Bimodal - Imbalanced دو قله‌ی نامتعادل 1000 160 و 190
Trimodal سه قله‌ای 1000 150، 170 و 190
Overlapping Modes دو قله‌ی هم‌پوشان 1000 160 و 175

۳. Box Plot در توزیع Unimodal

دیتاست Unimodal از یک توزیع نرمال با loc = 170 و scale = 8 ساخته شده است.

در این حالت، داده‌ها عمدتاً در اطراف ۱۷۰ متمرکز هستند و Distribution دارای یک قله‌ی اصلی است.

۳.۱. شکل مورد انتظار Box Plot

انتظار داریم Median در نزدیکی مرکز داده قرار داشته باشد و Q1 و Q3 نیز در دو طرف آن قرار بگیرند. به دلیل تقارن تقریبی توزیع نرمال، فاصله‌ی Median از Q1 و Q3 معمولاً نسبتاً مشابه خواهد بود.

همچنین Whiskerهای دو طرف نیز در یک توزیع نرمال تقریباً متقارن، طول مشابهی خواهند داشت.

بنابراین Box Plot این دیتاست معمولاً ظاهری نسبتاً متقارن خواهد داشت.

۴. Box Plot در Bimodal - Balanced

این دیتاست از دو گروه با اندازه‌ی برابر تشکیل شده است:

50 samples → N(155, 5)    |    50 samples → N(185, 5)

بنابراین دو گروه تقریباً به یک اندازه در Distribution حضور دارند.

۴.۱. اثر دو گروه روی Box Plot

به دلیل فاصله‌ی نسبتاً زیاد بین دو گروه، دامنه‌ی کلی داده‌ها افزایش پیدا می‌کند. در نتیجه Box و Whiskerها بخش وسیع‌تری از محور عددی را پوشش می‌دهند.

Median تقریباً در ناحیه‌ی میانی دو گروه قرار می‌گیرد. اما نکته‌ی مهم این است که Median لزوماً در نقطه‌ای قرار نمی‌گیرد که بیشترین تراکم داده وجود دارد.

نکته مهم: Box Plot در اینجا نمی‌تواند به‌تنهایی نشان دهد که Distribution دارای دو قله است. ممکن است Box Plot فقط یک Box نسبتاً بزرگ نشان دهد، در حالی که KDE یا Histogram دو قله‌ی کاملاً مشخص را نشان می‌دهد.

۵. Box Plot در Bimodal - Imbalanced

این دیتاست از دو گروه با اندازه‌های متفاوت تشکیل شده است:

75 samples → N(160, 5)    |    25 samples → N(190, 5)

بنابراین گروه اول سه برابر گروه دوم نمونه دارد.

۵.۱. اثر عدم تعادل روی Box Plot

به دلیل تعداد بیشتر نمونه‌های گروه اول، بخش بزرگی از ۵۰٪ میانی داده‌ها می‌تواند تحت تأثیر این گروه قرار بگیرد.

در نتیجه Median و Quartileها الزاماً در وسط فاصله‌ی بین دو گروه قرار نمی‌گیرند. موقعیت آن‌ها به تعداد نمونه‌های هر گروه و مقدار واقعی داده‌ها بستگی دارد.

این موضوع یک نکته‌ی مهم درباره‌ی Box Plot را نشان می‌دهد: اندازه و موقعیت Box به توزیع تجمعی داده‌ها وابسته است، نه صرفاً به فاصله‌ی بین قله‌های Distribution.

۶. Box Plot در Trimodal

دیتاست Trimodal از سه گروه تشکیل شده است:

35 samples → N(150, 4)    |    35 samples → N(170, 4)    |    30 samples → N(190, 4)

سه گروه تقریباً اندازه‌ی مشابهی دارند و از یکدیگر فاصله دارند.

۶.۱. شکل Box Plot

با وجود اینکه Distribution دارای سه قله است، Box Plot همچنان فقط یک Box برای کل داده‌ها ایجاد می‌کند.

بنابراین فاصله‌ی زیاد بین گروه‌ها می‌تواند باعث افزایش IQR و همچنین افزایش طول Whiskerها شود، اما تعداد قله‌ها مستقیماً در Box Plot نمایش داده نمی‌شود.

این مثال به‌خوبی نشان می‌دهد که Box Plot یک خلاصه‌ی پنج‌عددی از Distribution ارائه می‌کند و نه شکل کامل Distribution.

۷. Box Plot در Overlapping Modes

دیتاست Overlapping Modes از دو گروه با میانگین‌های ۱۶۰ و ۱۷۵ تشکیل شده است:

50 samples → N(160, 8)    |    50 samples → N(175, 8)

در این حالت، SD هر گروه نسبتاً زیاد است و فاصله‌ی بین میانگین‌ها نسبت به پراکندگی داده‌ها کوچک‌تر است. بنابراین دو گروه هم‌پوشانی قابل توجهی دارند.

۷.۱. اثر هم‌پوشانی

چون داده‌ها روی یکدیگر قرار گرفته‌اند، Distribution کلی می‌تواند شبیه یک توزیع نسبتاً پیوسته و پهن باشد.

Box Plot نیز معمولاً یک Box واحد را نشان می‌دهد و از روی آن نمی‌توان به‌راحتی تشخیص داد که داده‌ها از دو گروه مختلف ساخته شده‌اند.

نکته: هم‌پوشانی زیاد بین گروه‌ها باعث می‌شود تفاوت ساختاری آن‌ها در خلاصه‌های آماری مانند Quartileها کمتر قابل مشاهده باشد. برای بررسی این ساختار، KDE یا Histogram اطلاعات بیشتری ارائه می‌دهد.

۸. مقایسه‌ی Box Plotها

دیتاست ساختار Distribution تقارن تقریبی Spread قابل تشخیص بودن Modeها
Unimodal ۱ قله زیاد متوسط مناسب
Bimodal - Balanced ۲ قله تقریباً متقارن زیاد ضعیف
Bimodal - Imbalanced ۲ قله نامتقارن‌تر زیاد ضعیف
Trimodal ۳ قله تقریباً متقارن زیاد ضعیف
Overlapping Modes ۲ قله‌ی هم‌پوشان تقریباً متقارن متوسط تا زیاد بسیار ضعیف

۹. رابطه‌ی Box Plot با تعداد Modeها

یکی از مهم‌ترین نکات این مثال این است که تعداد Modeهای Distribution مستقیماً در Box Plot نمایش داده نمی‌شود.

یک Distribution می‌تواند:

  • یک Mode داشته باشد.
  • دو Mode داشته باشد.
  • سه Mode داشته باشد.
  • حتی تعداد بیشتری Mode داشته باشد.

اما Box Plot در همه‌ی این حالت‌ها فقط یک Box برای کل ستون نمایش می‌دهد.

دلیل آن این است که Box Plot بر اساس Quartileها ساخته می‌شود، نه بر اساس شکل تابع چگالی.

نتیجه مهم: اگر هدف تحلیلگر تشخیص Multimodality باشد، Box Plot ابزار مناسبی برای این کار نیست. بهتر است Box Plot در کنار KDE یا Histogram استفاده شود.

۱۰. Box Plot چه چیزی را بهتر نشان می‌دهد؟

با وجود محدودیت بالا، Box Plot برای مقایسه‌ی مرکز و پراکندگی بسیار مفید است.

در این مجموعه می‌توان با Box Plot موارد زیر را مقایسه کرد:

  • موقعیت Median
  • مقدار IQR
  • پراکندگی ۵۰٪ میانی داده‌ها
  • طول Whiskerها
  • تقارن یا عدم تقارن تقریبی
  • وجود مقادیر بسیار دور از بخش اصلی داده

اما برای فهمیدن اینکه این پراکندگی چگونه در Distribution سازمان‌دهی شده است، باید نمودارهای توزیعی مانند KDE یا Histogram نیز بررسی شوند.

۱۱. جمع‌بندی نهایی

  • Unimodal → معمولاً Box Plot متقارن‌تری دارد و مرکز Distribution به‌خوبی در اطراف Median خلاصه می‌شود.
  • Bimodal - Balanced → دو گروه متعادل دارد، اما Box Plot تعداد دو Mode را مستقیماً نشان نمی‌دهد.
  • Bimodal - Imbalanced → گروه غالب می‌تواند روی موقعیت Median و Quartileها اثر بیشتری داشته باشد.
  • Trimodal → با وجود سه قله، Box Plot همچنان یک Box واحد برای کل داده‌ها نمایش می‌دهد.
  • Overlapping Modes → به دلیل هم‌پوشانی زیاد، ساختار چندگروهی حتی در Distribution نیز دشوارتر دیده می‌شود و Box Plot اطلاعات محدودی درباره‌ی این ساختار ارائه می‌دهد.
  • Box Plot برای مقایسه‌ی Median، IQR، Spread و Outlierها بسیار مناسب است، اما برای تشخیص تعداد Modeها مناسب نیست.
  • برای تحلیل کامل Distribution چندقله‌ای، Box Plot + KDE / Histogram ترکیب بسیار مناسب‌تری است.
